# Synesis Risk Intelligence

Synesis is a Parma MCP App built with mcp-use v2. It provides an interactive MCP workspace for explainable contract-risk analysis, obligation extraction, suggested drafting remediation, and regulatory-impact mapping.

## MCP tools

- `open-synesis` — launches the interactive MCP App.
- `analyze-contract` — deterministic, explainable contract-risk analysis.
- `map-regulatory-impact` — maps regulatory-change text to affected control domains and an action plan.

The current release is an MVP and should be used as decision support, not a substitute for authoritative legal advice.
